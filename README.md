# BCG X NewCo Campaign Analysis

## Project Overview

This project was completed as part of the BCG X Data Science job simulation on Forage.

The project focuses on analyzing a one-week retail marketing campaign for NewCo, with the main objective of identifying which campaign and channel combination generated the strongest sales from new customers.

## Business Question

Which campaign and channel combination should NewCo double down on to grow new customer sales?

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Data Analysis
- Data Visualization

## Analysis

The campaign data was analyzed across:

- Campaign Type: Campaign A and Campaign B
- Channels: Email, Instagram, and Web Banner
- Customer Type: New and Existing

The analysis focused specifically on new customer sales because growing new customers was the client's main priority.

## Key Findings

Campaign A generated the highest new customer sales overall:

- Campaign A: $3,726.99
- Campaign B: $2,117.44

The strongest campaign and channel combination was:

- Campaign A + Email: $2,124.47

Other combinations included:

- Campaign A + Instagram: $969.46
- Campaign A + Web Banner: $633.06
- Campaign B + Email: $1,382.38
- Campaign B + Instagram: $416.14
- Campaign B + Web Banner: $318.92

## Recommendation

Based on the new customer sales analysis, Campaign A through Email should be prioritized for future campaigns focused on new customer growth.

The recommendation is supported by Campaign A + Email generating the highest new customer sales among all campaign and channel combinations.
